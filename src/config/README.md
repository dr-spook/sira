# config/

`game.json` : tous les chiffres réglables du jeu (gains de Cauris, coûts des indices, seuils de déblocage…).

- Ce fichier appartient au **pôle Game Design** : on ne le modifie pas sans eux.
- Dans le code, on lit toujours la valeur ici. Un `20` ou un `15` écrit en dur dans le code est un bug.
